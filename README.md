# A股次日涨超 5% 选股研究

<p align="center"><font color="red" size="6"><b>⚠️ 2025年10月23日至2026年10月23日（卖出日窗口）的模拟结果收益是负值，仅作研究用，不做投资建议！！！</b></font></p>

用近 30 年 A 股数据，寻找“次日大涨超 5%”股票的统计特征，并用模型做 Top10 选股排序。研究性质，不构成投资建议。

## 方案总览（原版去 weekday 方案，最终采用）

- **目标**：尾部事件分类，不是涨跌方向、不是收益率点预测。核心指标是排序与 Precision@K。
- **执行口径**（所有对比共用）：信号日 D 收盘打分 → 买入日 D+1 按 D 收盘价挂牌（买入日最低价 ≤ 信号收盘价才算成交）→ 卖出日 D+2 结算：卖出日最低价 ≤ 成本×0.98 按 -2% 止损，最高价 ≥ 成本×1.05 按 +5% 止盈，都没触到按卖出日收盘价结算；同日双触按止损算。标签 y=1 当且仅当成交且卖出收益 ≥ +5%。模型概率 = 成交且卖出收益≥+5%的概率，不是正收益概率。
- **特征**：29 个（去 weekday），全部只用信号日收盘前已知信息：波动（5/20 日收益率标准差、ATR14）、动量与位置（1/3/5/10/20 日涨幅、均线偏离、60 日高低点位置、20 日突破、连涨天数）、量（量比、大涨天数占比）、涨停（当日是否涨停、近 5/20 日涨停次数）、市场（上证涨幅、超额收益）、技术指标（RSI14、MACD）。复权价计算，涨跌停计数错开一天防未来函数。
- **模型**：HistGradientBoosting（300 棵、学习率 0.05、深度 3、叶最小 100、类别平衡、128 分箱）。股票按代码排序 %3 划分训练/验证/测试。
- **成绩**：验证集 Top10 命中 21.02%、每周期 +0.134%；测试集 20.70%、+0.097%。最近一年（卖出日 2025-10-23 至 2026-10-23）测试集模拟：执行率 91.53%、胜率 22.98%、每周期 -0.062%、复利 -5.70%。全历史为正、最近一年为负，策略有效性随行情衰减。

## 对比过的方案

同一执行口径下：gs-quant 本地版（-6.79%）、hikyuu 开源指标引擎版（-8.88%）、东财基本面 v4 版（-9.77%）、FMZ 策略库海龟快 20 日突破（-9.45%），均为最近一年复利、扣费前。原版去 weekday（-5.70%）仍是最好，但“最好”不等于赚钱。

## 文件说明

- `full_train.py`：特征公式（`build_features`）与 29 特征定义，理论起点先看 `reliable_features_and_models.md` / `features_spec.md`
- `full_download*.py`：行情下载（Yahoo 为主、新浪为股票池）；`full_build_features*.py` / `full_flow*.py`：特征与执行流水
- `new_train.py` / `new_retrain.py` / `new_sim.py`：新策略训练、训练+验证重训、最近一年模拟
- `search_70pct.py` / `search_fullmarket.py`：70% 把握超 2% 的策略搜索
- `gsquant_*.py` / `hikyuu_*.py` / `fund_v4*.py` / `fmz_candidates.py`：四条对比线
- `daily_pipeline.py`：工作日 17 点日报流水（当日行情→特征→打分 Top10→增量标签→重建模型→复核），`build_base_arrays.py` 生成增量重建用的基数组
- `eastmoney_*.py`：东财基本面数据抓取（试点/全量/修复）

## 运行

本仓库只含源码，不含数据与模型（数据 39GB，行情来自 Yahoo/新浪，需自行下载）：

```bash
pip install -r requirements.txt
python full_download.py        # 下载行情（慢）
python full_build_features_v3.py
python full_flow_batch.py
python new_train.py
```

gs-quant 与 hikyuu 对比线需要各自独立的虚拟环境（见原项目记录），与主流程无关。

## 风险声明

- 所有收益均为扣费前：未计手续费、滑点和税；挂牌成交按最低价近似，未计排队与部分成交；止损不是地板，跳空低开会亏得更多；T+1。
- 命中率不等于可实现收益；没有任何策略能保证单日 +5% 或平均 +2%。
- 仅供研究，不构成投资建议。
