# 部署文档

## 1. 环境要求

- Python 3.10–3.12（实测 3.12.3）
- 内存 ≥ 8GB：全量特征约 1440 万行，务必使用内存安全版脚本（见第 5 节），不要一次性把 25 个批次全读进内存
- 磁盘：源码 < 1MB；完整数据约 39GB（原始行情、特征批次、流水批次、东财基本面）
- 网络：能访问 Yahoo Finance（行情）、新浪行情中心（股票池与市盈率）、东财 datacenter（基本面，可选）

## 2. 安装

```bash
git clone <本仓库地址>
cd ashare-surge-strategy
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt   # pandas / numpy / scikit-learn
```

注意：pandas 3.x 与 sklearn 1.9 的 pickle 不向前兼容，旧模型文件需在同版本环境中加载。

## 3. 数据准备（按顺序执行）

| 步骤 | 脚本 | 产出 | 说明 |
|---|---|---|---|
| 股票池 | 新浪行情中心快照 API（`get_list.py` 参考） | `sina_hs_a_*.csv` | 沪深全量，剔除名称含 ST 的股票（整只剔除，宁严勿宽） |
| 行情下载 | `full_download.py` / `full_download_resume_v2.py` | `full_raw_partial.pkl` 等 | Yahoo chart 接口，多线程断点续跑；上市不足 200 天的股票单独存放 |
| 特征 | `full_build_features_v3.py` | `full_features_batch_v3_*.pkl`（25 个） | 29 特征公式见 `full_train.py: build_features`，全部复权价、只用收盘前已知信息 |
| 执行流水 | `full_flow_batch.py` / `new_flow.py` | `full_flow_new_*.pkl`（25 个） | 每行一个（股票，信号日），含买入/卖出模拟与标签 y_strategy |

东财基本面（仅 v4 对比线需要）：`eastmoney_pilot.py`（100 只试点）→ `eastmoney_full.py`（全量，网络超时是常态）→ `eastmoney_repair.py`（只重跑失败项，幂等）→ `fund_v4.py`（按公告日+1 天生效的防未来函数面板）。

## 4. 训练与验证

```bash
python new_train.py      # 内存安全版：分 split 训练 HGB（去 weekday / 含 weekday 两个版本）
python new_retrain.py    # 训练集+验证集重训，产出最终模型 new_model_HGB_nowd_trainval.pkl
python new_sim.py        # 最近一年模拟（卖出日窗口、测试集股票、3 份资金轮换）
```

模型参数（全仓库统一）：`HistGradientBoostingClassifier(max_iter=300, learning_rate=0.05, max_depth=3, min_samples_leaf=100, class_weight="balanced", early_stopping=False, max_bins=128)`。

股票划分：代码排序 %3，0=训练、1=验证、2=测试，同一只股不跨集。

## 5. 日报任务（工作日 17 点）

```bash
python build_base_arrays.py   # 一次性：由流水生成训练/验证基数组 daily_base_arrays/
# 之后每个工作日 17 点运行：
python daily_pipeline.py      # 不带日期参数即为当日（北京时间）
```

`daily_pipeline.py` 每步做什么：抓当日全市场日线 → 提 29 特征 → 当前模型打分 → 去掉名称含“退”/“ST” → 取前 10 → 拉当日市盈率（新浪快照，失败不阻断）→ 为 2 个交易日前的信号周期补增量标签 → 有新标签则用基数组+增量行重建 HGB（全量重训，HGB 无增量接口；临时文件+回读校验通过才更新指针，失败保留旧模型）→ 复核卖出日就是当日的上一批推荐 → 写 `daily_output/<日>.json` 与 `<日>_email.txt`。

cron 示例（每周一至五 17:00，北京时间）：见本仓库 `docs` 外的运维记录，核心就是跑上面两条命令并发邮件。

## 6. 对比线独立环境

- gs-quant：`gsquant_venv`，`pip install gs-quant`，只用无需高盛账号的本地函数（`sharpe_ratio` 需会话，已排除），脚本 `gsquant_*.py`
- hikyuu：`hikyuu_venv`，Python 3.10–3.13，`pip install hikyuu`（2.8.3）；注意 `/tmp` 若为小 tmpfs，安装时设 `TMPDIR` 到大磁盘目录；脚本 `hikyuu_*.py`
- FMZ 策略库：`fmz_candidates.py` 直接对流水做规则信号回测，无需 FMZ 账号

## 7. 常见问题

- **管道退出码为 0 但没产出**：长任务不要用 `| tail` 判断成功，以输出文件存在且可加载为准。
- **datetime64 精度**：pandas 3.x 存的是 datetime64[s]，日期转整数用 `.values.astype('datetime64[D]').astype(int)`，不要除纳秒。
- **浮点相等**：止损/止盈计数用价格触碰（touch）重算，不要用 `realized == -0.02` 精确比较。
- **Yahoo 限流/超时**：下载脚本自带重试与断点，隔一段时间重跑 resume 脚本即可。
- **东财 push2 在本机返回 502**：价格/快照类接口走新浪，基本面类走 datacenter-web。
